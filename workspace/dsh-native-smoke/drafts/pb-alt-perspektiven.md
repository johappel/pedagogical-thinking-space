# Verschoben: dieser Draft war fälschlich ein Service Request

Diese Datei enthielt zuvor einen vollständigen Service Request. Das entsprach
**nicht** der kanonischen PTS-Semantik.

Nach `harness/dispatcher.py` und `AGENTS.md` liegt ein Service Request unter:

```text
workspace/<project-slug>/service-requests/
```

`drafts/` ist der Ort für das Worker-**Ergebnis** (den
`pedagogical_alternatives_brief`), nicht für den Request.

- Kanonischer Request jetzt: [`../service-requests/pb-alt-perspektiven.yml`](../service-requests/pb-alt-perspektiven.yml)
- Erwartetes Ergebnis später hier: `drafts/pb-alt-perspektiven-alternatives.md`

Siehe `docs/experiments/DSH_NATIVE_WORKSPACE.md`, Abschnitt „Service Delegation Spike".

# PTS vNext – Architektur-Arbeitsstand

> **Status:** Arbeitsfassung. Noch kein Implementierungsvertrag.

Dieses Verzeichnis beschreibt den Pedagogical Thinking Space neu von der gewünschten Nutzung her. DSH wird als technische Laufzeit vorausgesetzt; der bestehende PTS-Stand dient als Fundus für bewährte Konzepte und als Migrationsquelle, nicht als Vorgabe für das neue Domänenmodell.

2. [`01_DOMAIN_MODEL.md`](./01_DOMAIN_MODEL.md) – minimale referenzierbare Objektwelt, Beziehungen, Projektionen und Lebenszyklen.
3. [`02_TAXONOMIES_AND_LENSES.md`](./02_TAXONOMIES_AND_LENSES.md) – lokale erweiterbare Taxonomien, fachliche Linsen und Kriterien dafür, wann etwas in den Core gehört.

## Arbeitsregel

Die Reihenfolge ist bewusst: zuerst Domäne und Interaktion, dann Persistenz und Migration.

> **Nicht die vorhandenen Dateien bestimmen das neue Modell. Das neue Modell bestimmt später, welche vorhandenen Dateien, Plugins und Konzepte weiterverwendet werden.**

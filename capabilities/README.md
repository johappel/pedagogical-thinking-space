# Capability Notes

Files below this directory are optional pedagogical task notes. They may help a
Companion formulate a precise Worker prompt, especially for weaker models.

They are deliberately not a runtime registry. A Markdown file does not become
executable through a status flag, and PTS contains no capability loader,
dispatcher, trial or activation lifecycle. Execution is provided only by the
role-specific DSH subagent tools configured in
`dsh-presets/pts-companion/agent.cordis.yml`.

When a note conflicts with the role's DSH persona or tool filter, the DSH role
boundary wins. New notes may be added as documentation without modifying
runtime routing.
